모드 1 · 템플릿

25종 갤러리 + 파라메트릭 노브

갤러리 25종

로딩 7 · 피드백 3 · 인터랙션 9 · 이펙트 6. 호버 재생, 검색, 최근 사용.

노브

템플릿별 슬라이더가 픽셀·도 절대 단위. 값은 항상 원본에서 재계산해 누적 왜곡이 없다.

그래픽 교체

벨·점·핀 같은 지정 슬롯에 내 SVG/PNG를 끼우고 앵커를 마우스로 맞춘다.

색 일괄 변경

문서의 단색 fill/stroke를 그룹으로 추출해 한 번에 교체.

텍스트 템플릿(숫자 카운트 등)은 로컬 폰트를 직접 고를 수 있고, 사용 예시 목업으로 폰 프레임 속 실제 UI 맥락에 얹어 확인한다.

모드 2 · 커스텀

그리고, 올리고, 모션을 조립한다

입력

업로드 · 드로잉 · 펜

SVG는 벡터 셰이프로 변환. 도형 툴(Q)과 일러스트레이터식 펜(G) — 2점부터 즉시 실제 레이어로 살아난다.

쉬운 길

등장 · 루프 · 퇴장 3슬롯

레이어마다 프리셋 조합. 루프는 클립에 정수 사이클로 맞춰져 끊김이 없다.

정밀한 길

키프레임 모드

AE 사용자용. 위치·크기·회전·불투명도 채널을 직접 편집, 재생헤드에 자동 키.

패턴 복제

개수·간격·회전·크기·시간차를 누적 오프셋으로 — 스태거 등장, 방사형 패턴.

다중 선택 (AE 방식)

마키 러버밴드, ⇧/⌘ 토글, 페이스트보드 드래그, 그룹 이동.

산술 입력

모든 숫자 필드에서 100+50, *2, /4.

코어

타임라인과 그래프 에디터

  • ms 눈금자, 레이어 트리, 프로퍼티별 키프레임 행 — 다이아몬드를 끌고 더블클릭으로 지운다
  • 구간 이징 팝업: 프리셋 · 베지어 핸들 드래그 · cubic-bezier() 수치 입력
  • 이징 토큰 — 내 커브에 이름을 붙여 프로젝트를 넘어 재사용
  • 그래프 에디터는 AE value graph 방식 — 키마다 in/out 탄젠트, 탄젠트 링크와 ⌥ 브레이크
  • AE 단축키 그대로: P S R T · U · J K · [ ] · ⌥[ ⌥]
EASE CURVE · 구간 이징

핸들을 끌면 값이 라이브로 갱신되고 ⌘Z 한 번에 되돌아간다.

최근 작업 · 2026-08-28

자연스러운 움직임을 적은 키로

"적은 키 + 후편집 가능" 노선. 물리를 곡선 샘플 키로 굽고(bake) 나면 결과는 평범한 키프레임이라 그대로 손댈 수 있다.

스프링 정착

감쇠 조화진동 닫힌형으로 오버슛→정착 극값만 키로. 출렁/보통/절제.

AI 자동 아크

위치 키 3개 이상이면 Catmull-Rom 곡선 경로를 자동으로.

다중 선택 레이어 키를 위→아래 4f(⇧ 8f) 계단 오프셋.

팔로우스루

부모 모션을 지연 샘플해 자식의 위치·회전 랙을 키로 굽는다.

결과

평범한 키프레임

블랙박스가 아니라 편집 가능한 키. 적용 후 자동 재생, ⌘Z 한 번에 원복.

호환

남이 만든 Lottie를 키프레임째 열어본다

Lottie / dotLottie 임포트

위치·크기·회전·불투명도 키프레임과 구간 이징을 xkf로 변환해 타임라인에서 그대로 편집. 시간은 60fps, 좌표는 512 캔버스로 환산.

부모 링크 해석

정적 체인은 행렬 합성으로 정확 변환(이징 보존), 움직이는 부모는 월드 트랜스폼을 키로 베이크.

씬 = 프리컴프

프리컴프가 있는 파일은 AE 컴포지션처럼 씬으로 보존. 타임라인 트리의 트월로 내부 레이어를 펼치고, 더블클릭으로 진입.

표준을 벗어나지 않는다

씬은 문서 안의 표준 comp 에셋이라 내보낸 JSON이 어느 플레이어에서든 그대로 재생된다.

한계 — 텍스트·매트·홀드 키·tm은 건너뛰거나 근사한 뒤 알린다.

출력

한 문서에서 여섯 갈래로

Lottie JSON

다운로드 또는 클립보드 복사. 배속 굽기 옵션.

dotLottie

manifest + 애니메이션 단일 파일. 의존성 없는 자체 zip 라이터.

WebM

컴포지션 1회 재생을 실시간 녹화, 배경색 포함 2x.

GIF

프레임 정확 인코딩(gifenc), 웹워커 오프로드로 UI 유지.

PNG

현재 프레임(투명 2x) 또는 시퀀스 zip.

.lmproj

에셋 내장(base64 + SVG 원문)으로 파일 하나로 완결. 드롭하면 이어서 편집.

자동 저장은 IndexedDB(localStorage는 소형 미러), 수동 버전 스냅샷 20개, 복원 전 자동 백업.
