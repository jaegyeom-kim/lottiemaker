# LottieMaker

로티(Lottie) 애니메이션을 빠르고 쉽게 만드는 웹 도구.
After Effects 없이 — 템플릿에서 시작하거나, 내 그래픽(SVG/PNG)을 올려 모션을 조립하고, 결과를 Lottie JSON으로 내보냅니다.

**라이브:** https://jaegyeom-kim.github.io/lottiemaker/

## 실행

```bash
npm install
npm run dev   # http://localhost:5173
```

## 두 가지 모드

왼쪽 사이드바 탭이 곧 작업 모드입니다. 탭·캔버스·우측 패널·타임라인이 항상 한 모드로 움직이고,
탭을 전환하면 작업공간이 통째로 스왑되므로(실행 취소 히스토리 포함) 어느 쪽 작업도 사라지지 않습니다.

### 템플릿 모드

- **갤러리 25종** — 로딩 7 · 피드백 3 · 인터랙션 9 · 이펙트 6. 호버 시 재생, 검색, 최근 사용, 현재 열린 템플릿 표시
- **파라메트릭 옵션** — 템플릿별 슬라이더(픽셀·도 절대 단위) + 직접 수치 입력, 토글, 선택 칩, 재생 길이
- **폰트** — 숫자 카운트 등 텍스트 템플릿은 프리셋 + 로컬 폰트(Local Font Access API, Chromium) 선택
- **그래픽 교체** — 지정 슬롯(벨, 점, 핀 등)에 SVG/PNG를 넣어 내 그래픽으로 교체, 마우스로 앵커 조정
- **색상 일괄 변경** — 문서의 단색 fill/stroke를 그룹으로 추출해 한 번에 교체
- **사용 예시 목업** — 폰 프레임 속 실제 서비스 맥락(다이얼로그/버튼/리스트/토스트 등)에 배치해 확인

### 커스텀 모드

- **그래픽 업로드** — SVG/PNG/JPG/WebP 여러 장, 드래그앤드롭(드롭 지점 배치) 또는 패널 업로드. SVG는 벡터 셰이프로 변환
- **씬 (컴포지션)** — 프리컴프가 있는 파일을 임포트하면 AE 컴포지션처럼 **씬으로 보존** (LottieFiles Creator 방식). 타임라인 위 씬 탭으로 전환, 캔버스에서 씬 레이어 더블클릭 = 진입. **타임라인 트리** — 씬 참조의 ▸ 트월로 내부 레이어를 들여쓰기 행으로 펼침(중첩 재귀), 행 클릭 = 그 씬 진입+레이어 선택. 씬 참조 레이어도 일반 레이어처럼 위치/크기/회전/불투명도 키프레임 편집 가능. 씬은 문서 안의 표준 로티 프리컴프(comp 에셋)라 **내보낸 JSON이 어디서든 그대로 재생**
- **로티 임포트 (키프레임 유지)** — 커스텀 모드에서 Lottie JSON·dotLottie(.lottie)를 드롭/업로드하면 레이어로 변환해 가져옴. 위치/크기/회전/불투명도 **키프레임과 구간 이징이 xkf로 변환**되어 타임라인에서 그대로 편집 가능, 셰이프 내부 애니메이션(패스 모프·트림)은 원본 유지. 시간은 60fps·좌표는 512 캔버스로 환산, 정적 스케일은 래퍼로 접힘. **부모 링크(널 포함) 해석** — 정적 체인은 행렬 합성으로 정확 변환(이징 보존), 움직이는 부모는 월드 트랜스폼을 키로 베이크. **프리컴프는 재귀 평탄화**(5단, 시간 리맵·클립 교차·불투명도 곱 반영)로 내부 레이어를 그대로 살림. 지원: 셰이프/이미지/솔리드 (텍스트·매트·홀드 키·tm은 건너뛰거나 근사 후 알림)
- **드로잉 툴바 (Figma 방식)** — 캔버스 하단 중앙 플로팅 툴바: 사각형·원·삼각형·별·선(Q 순환)·펜(G). 드래그로 그리기(⇧ 정비율/45°). 그린 도형은 일반 벡터 레이어 — 색상 일괄 편집·모션 전부 적용 가능
- **펜 툴 (일러스트레이터 방식)** — 클릭 = 점, 클릭+드래그 = 베지어 곡선. **2점부터 즉시 실제 레이어**로 살아나며 그리는 동안 라이브 갱신 — Esc·Enter·툴 전환 어느 쪽으로 끊어도 그린 만큼 레이어로 남음. 그리는 중에 **앵커·베지어 핸들을 직접 드래그**해 수정(⌥ = 한쪽 핸들만 꺾기), 시작점 클릭 = 닫힌 패스(fill), 열린 패스는 스트로크
- **등장 / 루프 / 퇴장 3슬롯 모션** — 레이어마다 조합
  - 등장: 페이드 · 아래/위/왼쪽/오른쪽에서 · 팝 · 드롭 (+오버슛 바운스, 딜레이, 시간, 거리)
  - 루프: 플로팅 · 펄스 · 흔들기 · 회전 · 바운스 (세기·주기 — 클립에 정수 사이클로 맞춰져 끊김 없음)
  - 퇴장: 페이드 · 아래/위/왼쪽/오른쪽으로 · 축소
- **키프레임 모드 (AE 사용자용)** — 레이어별로 프리셋 대신 채널(위치/크기/회전/불투명도) 키프레임을 직접 편집. 재생헤드에 자동 키(캔버스 드래그·방향키·값 입력·키 있는 채널의 슬라이더), 키 1개 = 정적(AE와 동일)
- **타임라인 (Figma Motion 방식)** — ms 눈금자, 레이어 트리 펼치면 프로퍼티별 키프레임 행(다이아몬드 드래그 이동·더블클릭 삭제), 키 사이 이징 버튼 → 커브 그래프 팝업(프리셋 + 베지어 핸들 드래그 + cubic-bezier 수치 입력 + **스프링·물리 굽기**(바운시/스내피/엘라스틱/낙하 바운스 — 구간을 곡선 샘플 키로 베이크) + **이징 토큰**(내 커브를 이름 붙여 저장·재사용, 프로젝트를 넘어 유지), 구간별 적용), 선택 키 **시간 반전(미러)**, 클립 드래그 이동(키 동반)·트림, 등장/퇴장 세그먼트 길이 조절, ⇧ 스크럽 = 키에 스냅
- **곡선 모션 패스** — 위치 키들을 부드러운 곡선(Catmull-Rom)으로 통과하는 스무스 보간 토글, 캔버스 모션 패스 오버레이도 곡선으로 일치
- **블렌드 모드** — 곱하기/스크린/오버레이 등 Lottie 표준 16종, 내보낸 JSON에 그대로 실림
- **패턴 복제** — 선택 레이어를 개수·X/Y 간격·회전·크기·불투명도·시간차 누적 오프셋으로 복제 (스태거 등장·방사형·페이드 패턴)
- **산술 입력** — 모든 숫자 필드에서 `100+50`, `*2`, `/4` 계산 입력
- **클립보드 이미지 붙여넣기** — 복사한 이미지를 ⌘V로 바로 레이어로
- **AI 모션 (베타)** — 원하는 모션을 문장으로 쓰면 키프레임을 생성 ("공이 위에서 떨어져 튕기게"). 내 Anthropic API 키(BYOK)로 브라우저에서 직접 호출 — 키는 이 브라우저 localStorage에만 저장되고 프로젝트 파일·내보내기에 포함되지 않음. 결과는 일반 키프레임이라 그대로 수정 가능, ⌘Z 한 번에 원복
- **캔버스 편집** — 이동(V)/핸드(H) 툴, ⌘+휠 줌·휠 팬, 스냅 가이드(중앙·사분점·모서리), 리사이즈 핸들(기본 반대 모서리 고정 · Alt 중앙 기준 · Shift 10px 스냅), Alt+드래그 복제, **다중 선택 (AE 방식)** — 빈 곳·**페이스트보드(컴프 밖)** 드래그 = 마키 러버밴드(⇧ = 기존 선택에 추가) · Shift/⌘ 클릭 토글 · ⌘A 전체 선택 · 타임라인 라벨/클립도 ⇧범위·⌘토글 · 그룹 드래그로 함께 이동
- **정렬 패널** — 일러스트레이터식 정렬 6종 + 균등 분배, 기준은 캔버스 또는 선택 영역
- **앵커 포인트** — 선택 박스의 ⌖ 버튼으로 팝업, 9점 그리드 + 드래그 패드. 그래픽은 제자리(팬 비하인드), 회전·스케일 피벗만 변경
- **컴포지션 길이** — 0.5~6초. AE 컴프처럼 늘려도 각 레이어의 애니메이션 타이밍은 절대 시간 유지
- **레이어 패널** — 이름 변경(더블클릭), 표시/숨김, 복제, 삭제, ≡ 드래그로 순서 변경, 레이어 라벨 컬러, **⇧클릭 = 범위 선택 · ⌘클릭 = 개별 토글**

## 저장

- **자동 저장** — 편집 멈추고 0.8초 후 localStorage에 기록. 템플릿/커스텀 슬롯 분리, 새로고침·창 닫기 직전에도 플러시. 상단바 배지가 실제 저장 결과를 표시(용량 초과 시 경고)
- **프로젝트 파일 (.lmproj.json)** — 에셋 내장(래스터 base64 + SVG 원문)으로 파일 하나로 완결. 미리보기에 드롭하면 이어서 편집
- **예제** — [`examples/커스텀-예제.lmproj.json`](examples/커스텀-예제.lmproj.json) 을 드롭해 커스텀 기능 전반(3슬롯 모션 · 스태거 · 클립 오프셋 · 앵커 피벗)을 바로 확인

## 내보내기

- **Lottie JSON** 다운로드 / 클립보드 복사 (배속 굽기 옵션)
- **dotLottie (.lottie)** — manifest + 애니메이션을 압축한 단일 파일 (의존성 없는 자체 zip 라이터, `CompressionStream` 지원 시 deflate)
- **WebM 영상** — 컴포지션을 1회 재생하며 실시간 녹화 (Chrome/Edge, 배경색 포함 2x 해상도)
- **프로젝트 파일 (.lmproj)** 저장
- 텍스트 템플릿은 사용 폰트 힌트를 함께 표시합니다.

```
  lib/lottieKnobs.ts     # 템플릿 파라메트릭 옵션 엔진 (줌/두께/진폭/개수 등, px·° 단위)
  lib/lottieColors.ts    # 색상 추출/치환 (fill·stroke, 정적+키프레임)
  lib/lottieUtils.ts     # 파싱/검증, 레이어, 리사이즈, 배속 굽기, 다운로드
  store.ts               # zustand 스토어 — 모드 스왑, 스냅샷 undo/redo, 자동 저장
  components/            # 프리뷰(캔버스·타임라인), 갤러리, 커스텀 빌더, 정렬/색상/레이어/내보내기 패널
  templates/             # 내장 로티 JSON 25종 + 노브 정의 레지스트리
examples/                # 커스텀 데모 프로젝트 파일
```

## 동작 원리 메모

- **노브**는 항상 노브 미적용 원본에서 전체 재계산 — 값이 누적 왜곡되지 않습니다. 진폭 계열은 첫 키프레임 기준 편차 조절이라 순환 루프가 깨지지 않습니다.
- **커스텀 레이어**는 표준 로티 문서에 확장 필드(`xsel` 슬롯 상태, `xkf` 키프레임 모드 상태, `xbase` 정착 위치, `xci` 라벨 컬러, `xsrc` SVG 원문)를 얹은 구조 — 로티 플레이어는 이를 무시하므로 내보낸 JSON은 어디서든 재생됩니다. ks 채널은 편집 때마다 `xsel`(프리셋) 또는 `xkf`(키프레임)에서 재생성됩니다.
- **컴포지션 길이** 변경은 `op`만 바꾸고 클립·키프레임은 절대 프레임을 유지 — AE 컴프 길이 변경과 같은 의미론입니다.
